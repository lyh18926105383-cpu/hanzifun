# HanziFun · 方案 C 本地结构原型

这是全站结构与交互方向的本地预览，不是上线版本。已有中文站源码、故事媒体与课程数据不作修改。

## 品牌方向

- 米白 #F6F0E5、朱砂 #B74432、墨绿 #243D35、古金 #B7955C。
- 字形印章 + HanziFun 字标；不沿用饭碗意象。
- 衬线标题、清楚的无衬线正文、淡彩人物与风景插画。
- 首页沿用确认的七段结构与最终英文副标题。

## 预览

从项目根目录依次运行：

    npm run build:site
    node prototype/build.mjs
    python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype/dist

打开 http://127.0.0.1:4173/ 。构建输出在 prototype/dist/，不会写入根目录站点源码。legacy/ 只复制现有站点构建白名单中的公开产物。

## 可操作内容

- 首页翻转字卡、移动导航、FAQ、场景点字。
- 26 个字的演示字典，支持汉字、无调/有调拼音、英文和示例主题搜索。
- Visual Dictionary 的桌面下拉、手机子菜单与字典内导航，均提供 HSK 2.0 / HSK 3.0 字库的直达入口；沿用 /academic/hsk-2/ 与 /academic/hsk-3/ 两个独立页面，字库内容仍处于规划状态。
- 四个固定闪卡组，翻卡后标记熟悉/再看，完成后复习本轮需要再看的字。
- 顶部 Sign in / Pricing；学习中心展示本机练习进度、生词本与最近记录，刷新后仍保留。登录表单展示框架但不收集凭据，具体结构见 ACCOUNT_FRAMEWORK.md。
- 三种风格的固定中文名示例，姓名输入只作展示，不分析姓名。
- 木的四笔示意、可打印六张基本字卡。
- 三个示例 Blog，文章和字卡内链；八个已有中文故事的目录入口。

HSK 全量字表、定时 SRS、账号同步、教师自定义组卡、OCR、生肖计算与纹身检查均标明规划状态。无收费、登录、联系表单提交或外部 API。Blog 没有伪造实时 Trends 数据。预览页面设为 noindex，robots 禁止抓取。

## 资源与来源

public/assets/seal.svg 是可编辑的字形印章。

三个 PNG 是针对方案 C 生成的插画，原始生成图已复制入项目：

- hero.png：米白底、墨绿树木，朱砂衣服人物倚树休息，左上留空，无文字。
- audiences.png：三个等宽方形画面，亲子阅读 / 城市旅人和列车 / 书桌前学习者，统一淡彩风格，无文字。通过 CSS 背景位置显示各画面。
- festival.png：金色满月、湖山、月饼与桂花，米白 / 墨绿 / 古金，无文字。

这些图使用方案 C 概念图作为风格参考，由内置 imagegen 生成。它们是概念视觉资产；学习提示与汉字正文由 HTML 提供。

## 后续实施界限

此版本用于确认品牌、首页层次、入口命名与路径。正式建设时需要补充经审核的字典与 HSK 数据、可访问性和性能完善、真实功能、站点迁移与重定向、SEO 元信息和生产发布流程。
