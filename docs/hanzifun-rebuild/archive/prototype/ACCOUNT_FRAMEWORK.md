# 登录与学习记录框架

已纳入 C 方案导航：首页右上显示 Pricing / Sign in / Try Free Flashcards / 中文；手机菜单保留相同入口，并提供 My learning。

## 路径与状态

| 路径 | 作用 | 此原型状态 |
| --- | --- | --- |
| /sign-in/ | Google / 邮箱登录布局，进入个人学习中心 | 登录表单停用，不收集凭据；可体验本机学习中心 |
| /account/ | 已练汉字、熟悉汉字、待复习、近期练习 | 从真实本机操作产生记录 |
| /flashcards/my-words/ | 收藏与练过的字、熟悉程度、逐字/整组复习 | 本机保存 |
| /dictionary/{字}/ | 收藏入口、进入单字练习 | 本机保存 |
| /pricing/ | 免费试用与后续计划入口 | 价格待定，无支付 |

## 演示中已实现的数据流

1. 在字典点 Save to my words，加入生词本。
2. 闪卡先翻面再选择 I remember / See it again，立即保存该字最近一次选择与练习次数。
3. 完成一组后保存时间、练习字集合、总字数与需再看字数。
4. My learning 根据记录计算三个统计模块，并提供待复习入口；历史项可以重访当时那一组字。
5. 刷新页面或重新打开本机预览后记录仍在；与原中文站的学习数据采用不同存储键。

存储键：hanzifun.prototype.learning.v1。最近保留 30 次练习，主页显示最新 8 次。它是当前浏览器、当前源的演示数据，没有客户身份认证，也没有跨设备保存。

## 正式账号后端建议

建议实体：

- User：认证服务用户 ID、显示名、界面语言、创建时间。
- SavedWord：userId、characterId、收藏时间。
- CharacterProgress：userId、characterId、最近评价、累计练习次数、最近练习时间；SRS 上线时再增加到期时间和调度参数。
- PracticeSession：userId、deckId、练习项目 ID 集合、起止时间、汇总。
- ReviewEvent：唯一事件 ID、userId、characterId、评价、时间、sessionId。用于幂等同步和记录审计。

认证成功后再将本机记录与用户账户绑定。游客记录合并应由用户选择；复习事件按唯一 ID 去重，单字最近状态由较新的有效事件决定，不能用整份旧数据覆盖新记录。正式定时 SRS 需要单独定义与验证，不能把当前熟悉/再看按钮当作已实现的 SRS。

后端可围绕当前用户资料、收藏增删、复习事件提交、学习概览和练习历史提供接口。授权应从登录会话读取 userId。真实身份认证、跨设备同步、账号管理与付费均未在当前原型中实现。
