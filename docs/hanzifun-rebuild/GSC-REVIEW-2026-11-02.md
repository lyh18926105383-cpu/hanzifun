## 5. 汇总差异与待核验项

页面表曝光合计 **101**，图表为 **86**。两者保持各自口径，不强行改成一致：页面统计可分别计入同一搜索结果中的多个URL，站点统计则聚合该站点结果。[Google聚合口径](https://support.google.com/webmasters/answer/17011364?hl=en)

页面表包含 `returnTo`、`?char=` 参数，以及 `/story?lesson=...` 和 `/story.html?lesson=...` 两种历史地址。这值得做抽样规范网址核验，但不是已证明的重复收录问题：

- 本地 `site/seo.mjs` 已有去除query/hash的canonical函数；不能声称项目完全没有canonical。
- 需要GSC URL Inspection核对Google实际选择的canonical、最近抓取，以及实际HTTP/HTML行为。历史导出不能直接证明当前配置错误。
- 不因出现参数就全部重定向或noindex；`char`/`lesson`等参数可能承载真实交互或课程身份，任何修改须保持现有功能。
- 本次没有页面索引/站点地图报告，不能判断缺曝光主要来自未收录、搜索需求不足、竞争或上线时间短。48个有曝光URL也不能与404个可索引URL直接相除得到收录率。
- 国家/设备统计可做后续观察，但总共2点击不足以确定目标市场或设备转化表现；GSC不提供本次练习完成、回访或付费指标。

这是基于本次数据的总控建议，尚未派发。与[项目开发盘点](REMAINING-TASKS-2026-11-01.md)并行保留：完整产品开发可以继续87字路线，SEO优先时采用下列顺序。

| 顺序 / 任务 | 范围和交付 | 建议责任 |
|---|---|---|
| SEO-01 索引与规范网址核验 | 查看GSC页面索引/站点地图，抽查首页、三类已有曝光入口、参数URL与最新发布页；区分确认缺陷、正常状态、尚待抓取。实际改动前完成R-00开发基线准备 | Codex先做只读诊断；确认的局部代码问题再交Cursor |

| SEO-03 小范围现有页面优化 | 从SEO-01/02中选明确问题，完善正文、真实功能说明、标题描述和相关内链；保留URL与学习记录。范围由证据决定，不以字数或批量数量为目标 | Cursor Composer2.5实现明确规格；Codex集成验收 |
