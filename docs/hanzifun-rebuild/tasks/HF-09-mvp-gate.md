## 实施步骤

1. 冻结候选代码/数据版本，重跑已有与新增相关测试，确保旧测试覆盖没有被删减。
2. 按真实用户旅程查水→视觉→笔顺→again→保存→刷新→到期复习，追加空态/失败/无 JS 可读。
3. 验桌面/手机三处 HSK 入口、首级源表覆盖、两条场景和卡组联动。
4. 用旧 learning/story/prototype 夹具演练检测/选择/去重/未映射/跨 origin 导出导入。
5. 按故事规则阅读资料后，对八课及旧中文卡片完整回归；视听和人工确认如有未完成，单列阻断而不伪称完成。
6. 检查 noindex/robots/资源路径/404/安全边界和预算，汇总 P0/P1 问题并修复后只重测受影响范围。
7. 补验字页 Information、多音切换、简繁与 Kanji 条件展示；从独立拼音表选音节→听音→索引/已有字页→独立笔顺→返回。检查两工具的导航、选中字、手机/键盘操作和独立 canonical。
