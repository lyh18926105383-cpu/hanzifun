## 目标

把两个 HSK 入口和旅行/商务入口变成可验证的初始学习路径。

## 前置材料

- SOURCES.md 中 HSK 2.0 2015 与 HSK 3.0 当前大纲；来源锁、已确认限定使用范围与成员关系 schema。
- 真实字页/卡组/收藏接口；两个原型场景与用户已确认 URL。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 两版本首级词表/字表解析和覆盖呈现；restaurant/icebreakers 两个各至少 3 句的场景。

## 非目标

- 不完成全量高级 HSK，不重建同义字库 URL，不把 2021 标准直接当新版考试大纲。

## 明确交付物

- 两套首级 membership 数据与实际分母/覆盖报告，源页码/行号及人工抽查记录。
- 版本/级别/词-认读字-书写字筛选、受控卡组生成；剩余等级规划状态。
- 两个审核场景、拼音英译/音频、可点字词映射与学习闭环。

## 实施步骤

1. 锁定实际官方文件，只提取字/词头、版次和等级/清单归属，区分认读、书写、等级新增/累计；按下方指令放行，保留来源署名，不等待新的书面授权。
2. 对首级全量解析并计数，HSK 2.0 提取字注明 derived-from-vocabulary；新增关联字按 Tier 2 补齐，释义/读音来自 CC-CEDICT、笔顺来自许可数据，短例句和一句助记自研快审。只因缺插画或长故事不得 noindex。
3. 显示来源/版次/适用说明/实际覆盖，7—9 不虚拆，未完成级别不伪装满库。
4. 生成固定版次卡组，复用同一字典与调度；版本切换不串错收藏/进度。
5. 审两场景各 3 句，词语边界、礼貌语境、音频和英译一致；点击→字页→卡组→保存再返回场景。

- [ ] 两套首级源表与生成计数完全对齐；每行可追溯；没有将原型 26 字标为 HSK 完整库。

- [ ] 每个场景至少 3 句，相关字词都可解释、练习/收藏，音频与目标读音匹配。

- [ ] 新增 HSK 字按 Tier 2 或 Tier 1 发布；不等待专属插画，字数/词数/核心并集与索引页数分别列出，完整源范围与教学覆盖分开显示。

## 验证方法

- 自动全量计数/引用/级别检查；每套首级人工抽查至少 30 条（不足则全量）。
- 核查两个版本相同字不同词级别、多音/繁简以及累积数量；固定首尾行夹具。
- 移动和桌面走 HSK→词/字→练习→学习中心与两条场景旅程。
