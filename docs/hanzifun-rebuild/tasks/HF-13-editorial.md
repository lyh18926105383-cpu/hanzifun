## 目标

将样例内容升级为有来源、审核和学习联动的公开内容，并交付可用打印卡。

## 前置材料

- 原型三篇样文/分类、文章 schema、字词/卡组接口、SEO 发布状态。
- 适用官方事实来源；若使用趋势选题需真实查询证据，尚未取得不作趋势宣称。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 文件式内容工作流、首批 3–5 篇正式文章、家庭/课堂两组打印卡、已有场景内容补充；静态发布和本机学习联动。

## 非目标

- 不批量生成低质量 SEO 页面、不自动定时抓趋势或向外发帖、不改故事课。

## 明确交付物

- content/ 的 draft/reviewed/published/archived schema 和发布校验。
- 首批至少三篇实质内容（文化/旅行商务/家庭各一篇），目标 3–5 篇；每篇有引用、真实作者/审核者、日期和字卡关联。先发布合格三篇，4–5 篇可继续补充。
- A4/Letter 两组可打印卡及屏幕说明；编辑检查清单。

## 实施步骤

1. 逐篇核对样文事实与文化解释，补实质内容、准确英译和来源，不虚构作者资历。
2. 设置发布日期/修改日期、slug/canonical/description/alt/相关字卡；发布日期不是构建时间。
3. 有真实 Trends 证据才使用趋势措辞；否则按常青主题写作并记录来源。
4. 制作家庭/课堂卡组，校对拼音、英义、汉字与许可归属；禁止无授权教材扫描。
5. 把通过审核的内容转为可索引，保持草稿/占位页 noindex；验证每篇能回字典、闪卡和本机收藏。使用静态构建，不把 CMS 后端、账号或数据库作为前置；各文章/打印批次经 HF-17/18 发布。

## 验收条件

- [x] 至少三篇、目标 3–5 篇正式文章有来源和审核，正文不把 mnemonic 当字源或伪造热点；未完成第 4–5 篇不阻塞前三篇发布。
- [x] 每篇至少关联 3 个字/词和一个有效卡组；相关链接不指向缺失或未公开私人内容。
- [x] A4 与 Letter 打印无截断、分页合理，文字清楚、归属完整。
- [x] 没有修改旧故事课程；文案中的能力承诺与实际发布阶段一致。
- [x] 无登录/云同步也能访问文章、打印和继续本机练习；发布后的文章有自身 canonical 和 sitemap 条目，未依赖 HF-11。

## 验证方法

- 内容 schema/链接/日期/元信息检查，人工中英内容审读。
- 浏览器打印预览核验两纸型并导出样张；逐篇文章到字页/练习的 E2E。
- 状态切换前后比较 sitemap/noindex，draft 不能泄漏进公开包。

记录命令/结果、测试环境与日期、代码/数据版本、适用截图和尚未验证项。测试必须对准行为风险；旧测试和新验收分别记录，不扩大成无关施工。
