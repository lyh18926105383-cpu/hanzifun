## 目标

让教师从真实字词与 HSK 范围创建自己的可练习、可打印卡组。

## 前置材料

- 账号与同步权限、Deck/Card schema、已有字词/首级 HSK、打印接口。
- SPEC 2—100 项限制、私人默认和内容版本快照。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 私人卡组 CRUD/排序/版本、导入受控条目、练习/打印；教材映射规范。

## 非目标

- 不做班级/未成年名单/作业成绩/公开社区；不扫描未授权教材。

## 明确交付物

- /flashcards/teacher/ 的可用工作区与私人组存储/授权接口。
- 卡组版本与历史内容快照、重复/未收录校验、练习/打印导出。
- 教材 edition/chapter/permission schema；有明确授权才加入实际映射。

## 实施步骤

1. 从字/词搜索和 HSK 筛选添加，展示重复/未收录，不允许创建无解释的伪词条。
2. 实现增删/排序/重命名，发布新 deck version；保存用 operationId/revision，离线冲突可恢复。
3. 练习固定内容快照，编辑/删除卡组不抹掉既有会话历史。
4. 服务端验证 owner，所有页面/打印/API 按权限；猜中 slug 也无读取权。
5. 教师打印只输出教学内容、不输出邮箱/学习历史；教材仅许可明确后建立映射。

## 验收条件

- [x] 教师可创建 2—100 项卡组、修改、重开练习并打印；重复/未收录/超限反馈明确。
- [x] 编辑后旧会话仍显示旧版本内容；删除组不删独立学习历史。
- [ ] A 不能读写/打印 B 私人组，未登录不能访问；默认不进入 sitemap。
- [x] 无授权教材时如实保持规划状态，组卡功能仍可完整验收。

## 验证方法

- 权限矩阵与版本/删除/重复提交测试；2/100/101 项边界。
- 两账号浏览器交叉访问、编辑后重访旧会话、手机排序与打印预览。
- 同步冲突和断网保存后恢复，不改变 HF-11 既有隔离行为。

记录命令/结果、测试环境与日期、代码/数据版本、适用截图和尚未验证项。测试必须对准行为风险；旧测试和新验收分别记录，不扩大成无关施工。
