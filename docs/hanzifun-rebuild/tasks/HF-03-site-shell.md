## 目标

将已确认原型变成可维护的静态站点骨架，保持文案、三类人群和所有已确认入口。

## 前置材料

- 已保全原型 README/home.html/site.mjs/public/styles.css/public/app.js/layout.html/build.mjs。
- 契约 routes.json、原始插画与印章、SPEC 首页逐字文案和路由表。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 布局、七段首页、导航/页脚、移动导航、响应式 token、公开构建隔离和状态页。

## 非目标

- 不接登录或付款；不把固定姓名/静态文章/木笔顺改标为正式工具；不改故事播放器内容。

## 明确交付物

- site/ 布局与路由生成器、英文样式/组件、七段首页；新增公开支撑页骨架。
- 带状态/索引策略字段的 route manifest，77 个原型路径的逐项处理映射。
- 独立 /stroke-order/ 和新增 /pinyin-chart/ 的页面骨架与导航入口；新增路径单列，不把历史原型 77 个路径的数量改写为当前目标总数。
- 英文/中文资源隔离与静态 404；构建白名单和预览/生产模式配置接口。

## 实施步骤

1. 复用 C 色板、印章、插画和七段层次，图片生成适当压缩尺寸并保留原图。
2. 将标题、支持文案和完整副标题写入唯一内容来源，做 DOM 文本一致检查。
3. 实现桌面/手机导航、Visual Dictionary 的 All Characters / Stroke Order / Pinyin Chart / HSK 2.0 Library / HSK 3.0 Library 五个入口及字典内导航；键盘、Escape、焦点均有行为。笔顺与拼音表保持根目录独立 URL。
4. 按路由 manifest 生成静态正文/占位说明/404；未开通功能显示实际状态和可用学习入口。
5. 建立页面按需 JS 加载与新资源前缀，避免与旧根 app.js/styles.css 覆盖；不带入原型 legacy 整站重复输出。
6. 为 HF-04/06/07/08 留出明确挂载点和元信息接口，构建在本机可审阅。
7. 首页/着陆页优先使用已经完成的 Tier 1 插画字卡；未完成增强时可用成熟 Tier 2，不显示虚构插画或空位。六个 FAQ 输出为可读取 HTML 问答，按当前阶段回答并链接相关功能。
