## 目标

完成查字→笔顺→闪卡→保存→刷新可恢复的真实本机闭环，并无损承接旧数据。

## 前置材料

- IndexedDB Repository 契约、真实字典/卡组、interval-v1 组件。
- storage.js、story.js 与原型 app.js 的三种旧数据结构；旧音效/语言偏好键清单。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 本机事务仓储、/account/、/flashcards/ 系列、my-words、导入导出和本机错误恢复。

## 非目标

- 不接身份或跨设备；不删除旧键；不把旧摘要补造为逐次评价；不承诺整站离线。

## 明确交付物

- 新版 IndexedDB schema/迁移器、Repository 实现、事件+状态+游标原子写入。
- 学习中心、独立收藏开关、最近历史与分页、续练/到期入口。
- 三旧源适配、导入预览/去重、导出 JSON、失败恢复与清理确认。

## 实施步骤

1. 定义数据库版本升级/恢复路径，写入事务失败保留内存练习并显示未保存。
2. 接入四组和单字练习，评价后真实落盘，恢复同一会话而非重新选卡。
3. 实现唯一字数与卡数分口径、收藏与练过分离、最近 8 条展示但不丢其余事件。
4. 实现来源/origin/hash 导入批次，旧 sessions 与汇总避免重复相加；原型导入明确标注来源。
5. 处理未匹配字/课程、重复导入、损坏 JSON、大文件、schema 不支持；预检后事务导入并保留原始数据。
6. 加多标签事务/revision 保护、存储拒绝/配额错误、导出及明确的清空本设备操作。

## 验收条件

- [ ] 学习水→again→刷新后记录和游标保持，10 分钟后进入到期队列；known 不等于永久掌握。
- [ ] 收藏取消只改变收藏，不删学习历史；完成页不因重载重复增加一次会话。
- [ ] 同一批旧记录重复导入无新增；两次出现的“睛”教学位置保留且唯一字统计为 1。
- [ ] hanzifun.learning.v1、hanzifun.story.v1、原型键均保持不变；localhost 数据不能被伪称已自动迁往生产。
- [ ] 存储被拒绝/损坏/配额满仍能练习，清楚说明保存结果；多个标签页不会互相整库覆盖。

## 验证方法

- 使用真实 IndexedDB 浏览器测试，验证重载/关页/多标签/断网后当前会话保存。
- 固定三种旧样本、重复导入、汇总重叠、未映射字、错误版本/非法字段夹具；比对导出前后语义。
- 1,000 卡/10,000 事件下测摘要与续练性能；关键流程录屏或截图交给 HF-09。
