## 目标

建立可重建、可追溯、有许可记录的真实数据底座，提供 126 字核心集与 HSK 后续导入契约。

## 前置材料

- 冻结的 Character/Lexeme/Reading/StrokeAsset/SourceRelease、KanjiRelation、PinyinSyllable schema；SOURCES.md 的维护者与官方入口。
- characters.js、tts-corpus.js、audio-manifest.json、原型 data.mjs；107+26 并集清单。

所有相对源码路径以项目根目录为基准；先读 [基线证据](../BASELINE.md)。如果前置交付缺失，先记录精确缺项，不能把未完成依赖视为已通过。后续实施可采用等价目录，但须在交付记录里更新映射。

## 涉及范围

- 数据获取与许可证归档、解析/规范化、稳定 ID、核心字/词/读音/笔画、Information 基础字段及已核实 Kanji 关系、拼音表音节/音频、覆盖统计。

## 非目标

- 不把所有 CC-CEDICT 数据打包到浏览器；不批量生成历史字源；不替 HF-07 发布 HSK 等级页。

## 明确交付物

- data/sources.lock.json、data/coverage.json、核心 126 字 manifest、数据 schema。
- 两级内容契约：contentTier 与 reviewStatus/publicationStatus 分开；覆盖统计分别列核心字、HSK 关联字、Tier 2 可用数、Tier 1 增强数，不把没有插画算作数据不可用。
- 可重复导入/校验脚本、许可及归属文件、来源修订差异报告模板。
- 核心条目的 normalized 数据与按字分包笔画；原有 TTS 可复用/需补充的读音清单。
- Information 数据：按语境的简繁关系、部首/结构/当前字形笔画数；Kanji 关系及来源、核验状态清单。
- 拼音表数据：固定范围的合法音节清单、规范拼写/声调、例字、审核音频映射与缺项报告；独立统计，不受 126 字读音覆盖限制。

## 实施步骤

1. 获取可使用的下载数据，固定 release/日期/sha256；CC-CEDICT/笔画分别保存许可。HSK 字/词头与等级归属按下方限定范围指令登记 approved-with-scope，不因未取得书面授权默认设 pending；其他真正未知的素材再利用权单独处理，不从查询界面批量抓取。
2. 解析 CC-CEDICT 义项/读音、Unicode/部首补充、笔画路径，区分代码许可与 Arphic 数据许可。
3. 建立多音、简繁非一对一、词/字 ID 及旧卡 occurrence→characterId 映射；补齐 Information 基础字段，以所用字形/地区核对笔画数。
4. 生成 126 字核心数据；每字笔画路径/中线数量、字形对应、来源引用和加载资源检查。
5. 原音频按读音/词境识别，标出不适用的“字+组词”音频，生成精确补录需求但不自动批量消费 TTS。
6. 创建 HSK system/edition/itemType/membershipKind 契约，保留原始来源定位、署名、usageScope 与用户已确认的使用决策，供 HF-07/14 直接生成公开页面；不复制官方题目、释义/例句和版式。
7. 对核心字逐项登记 Kanji 核验状态，按固定来源审核同字或对应字形关系；来源未收录不等于日语不存在。不新增独立日语词典或读音课程。
8. 按《汉语拼音方案》整理可教学的音节表，标明罕见/儿化范围；核对合法声韵组合、标调和特殊拼写。每个开放播放的音节/声调绑定实际审核音频，单独交付补录需求，不自动消费外部 TTS。

## 验收条件

- [x] 核心集恰好 126 个唯一字，原 108 个教学位置仍可还原；不存在未解释的去重。
- [x] 每条公开数据有实际版本/hash、来源及适用许可/使用范围结论；HSK approved-with-scope 不被误判为等待第三方授权，也不伪写已取得许可证；真正受限素材不进入发布清单。
- [x] 核心笔画全量通过结构验证且资源可加载；缺数据不会被算入已完成覆盖。
- [x] 同一输入重跑产物一致，原始文件升级产生可审阅 diff；多音字和 ü 检索形式不丢失。
- [x] 126 字的 Information 基础字段可用，简繁同形/不同形/一对多有明确表示；关联字形不自动扩大核心字数量。
- [x] 核心字的 Kanji 核验状态逐项记录，已核实关系带来源定位并可供页面展示；待核实/所查来源未收录不伪写为“没有 Kanji”，缺失读音也不作为否定证据。
- [ ] 拼音表覆盖相对于固定音节清单可计算；无机械生成的非法组合；合法声调、示例读音与实际音频匹配，未审核或缺失资源不会出现可点击的假播放。
- [ ] Tier 2 支持无插画、短 VisualNote 和真实独体/部件说明；升级 Tier 1 不新建 ID/URL。核心 126 与 HSK 并集去重，唯一字数、词数、可发布页数分别统计。

## 验证方法

- 全量 schema、引用、计数、唯一性、哈希与构建可重复校验。
- 人工逐项审核心字读音/英义，笔顺抽查至少 20 字并涵盖多音/繁简/复杂字；有异常扩大到受影响类别。
- 为坏数据、重复读音、缺许可/资源设失败夹具；只验证数据风险，不写大量镜像实现的测试。
- 覆盖简繁同形、一对多、多音、不同地区笔画数、Kanji 已核实与未核实；拼音覆盖零声母、ü、缩写、标调与缺音频。逐项审核首发音频的音节/声调，统计不能代替听音。
